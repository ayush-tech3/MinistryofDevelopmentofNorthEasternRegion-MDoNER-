# AlertNex Presentation Materials

Presentation slide decks and slide generation scripts for **Smart India Hackathon 2026** (Problem Statement ID: **SIH26001**):

### PowerPoint Presentations
* **`SIH2026_AlertNex_Official_6Slides.pptx`**: Official 6-slide SIH format presentation.
* **`SIH2026_AlertNex_SIH_Template_6Slides.pptx`**: Standard SIH presentation template deck.
* **`SIH2026_AlertNex_Extended_10Slides.pptx`**: 10-slide comprehensive technical presentation.
* **`SIH2026_AlertNex_Presentation.pptx`**: Interactive demonstration overview deck.

### Presentation Generation Scripts & Assets
* **`build_sih_official_ppt.py`**: Python script using `python-pptx` to generate the official SIH slide deck.
* **`build_alertnex_white_ppt.py`**: Presentation builder for high-contrast white-theme slide decks.
* **`generate_ppt.py`**: Core slide generation script.
* **`sih_*.png`**: Presentation backgrounds, extracted icons, and Ministry/SIH branding logos.

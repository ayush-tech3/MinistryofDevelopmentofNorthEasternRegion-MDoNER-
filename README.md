# MinistryofDevelopmentofNorthEasternRegion-MDoNER-
MDoNER, established in 2001, is the nodal Ministry of Government of India for socio-economic development of 8 North Eastern states — Assam, Arunachal Pradesh, Manipur, Meghalaya, Mizoram, Nagaland, Sikkim &amp; Tripura. It plans, executes &amp; monitors development schemes like PM-DevINE &amp; NESIDS.

# AlertNex Documentation

Official project documentation and submission materials for **Smart India Hackathon 2026** (Problem Statement ID: **SIH26001**):

### Submission Files
* **`SIH2026_Idea_Description_AlertNex.md`**: Complete Markdown idea submission document detailing project scope, problem statement, architecture, GIS connectivity intelligence, and academic honesty disclosures.
* **`SIH2026_AlertNex_IdeaDescription.pdf`**: Official formatted submission PDF document.
* **`SIH2026_AlertNex_Idea_Description_4Pages.pdf`**: 4-page executive brief submission PDF.
* **`SIH2026_AlertNex_Idea_Description_NiT.pdf`**: Institutional submission PDF version.

### Document Generation Scripts
* **`build_alertnex_4page_pdf.py`**: Python FPDF2 script for compiling the 4-page submission PDF.
* **`generate_pdf.py`**: Automated PDF report generator script.
* **`clean_pdf_script.py`**: PDF cleanup and formatting utility.
